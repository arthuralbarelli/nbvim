Terminal UI

Jupyter notebooks, with vim keys.

Open or create a .ipynb, move between cells like vim, and run Python in your active environment — all in the terminal.

Install

pipx install nbvim
nbvim path/to/notebook.ipynb

Python 3.13+

GitHub PyPI

Keybindings

Bindings apply in navigation mode unless noted. The cell editor uses Insert, Normal, and Visual.

Navigate

j k Next / previous cell
a b Add cell above / after
c v Copy / paste below
dd Delete cell
Enter Edit (starts in Insert)
Esc Back toward navigation
r R Run, then next / stay
m Markdown ↔ Python
: Command bar

Edit

i a Insert at / after cursor
h j k l Move
0 $ Line start / end
x Delete character
dd cc yy Delete / change / yank line
p u Paste / undo
v V Character / line Visual

Commands

:w Save
:q Quit without saving
:wq Save and quit
:q! Quit without saving

Leaving the UI any other way saves the notebook automatically.
